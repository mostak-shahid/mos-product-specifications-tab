== Description ==

Product Specifications Tab for WooCommerce allows you to display detailed product information in a clean, structured, and professional specification table inside a dedicated WooCommerce product tab.

Clear product information builds trust. The more organized and detailed your product data is, the easier it becomes for customers to make confident purchase decisions.

This plugin helps you:

* Display unlimited product specifications
* Organize technical details in structured tables
* Improve product page SEO
* Reduce customer confusion
* Increase buyer confidence
* Lower return rates

Built with performance in mind — it is lightweight and will not slow down your website.

== Why Product Specifications Matter ==

Modern customers compare products carefully. A structured specification table:

* Builds credibility
* Improves conversion rates
* Reduces pre-sales questions
* Enhances product clarity
* Strengthens search visibility

If you sell technical, configurable, or detailed products, structured specifications are essential.

== Installation ==

= Using WordPress Dashboard =

1. Go to Plugins → Add New
2. Click Upload Plugin
3. Upload the plugin ZIP file
4. Click Install Now
5. Activate the plugin

= Manual Installation via FTP =

1. Extract the plugin ZIP file
2. Upload the plugin folder to /wp-content/plugins/
3. Activate the plugin from the WordPress Plugins menu

== How to Use ==

1. Edit any WooCommerce product
2. Go to the Product Data section
3. Click on the Specifications tab
4. Add unlimited specification rows
5. Save the product

The specification table will automatically display on the product page.
